## Description

This repository contains project instructions for project work to be completed by associates in Revature TRNG-2499

For each project, you (and your Team, if applicable) will create a separate Github Repository to contain your project's codebase. Each project you complete should have a history of commits (i.e. work on your project, and commit code regularly. You should ***not*** have a single commit at the end with your complete project code).
